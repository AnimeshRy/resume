## Innovation Management Platform

Core contributor to a **national Innovation Management Platform** serving **30K users** across **30+ educational institutions** — built on **Django**, **Next.js**, **Redis**, and **AWS** with **OpenAI-powered** features for ideation and collaboration.

## Technical decisions (one-way doors)

- **Redshift + OpenAI** for the patentability pipeline — bet on a warehouse-shaped workflow for document-heavy assessments; tuning queries and cost became the ongoing trade-off versus a lighter OLTP-only design.

## Patentability Engine

Built a **Patentability Engine** in **Node.js** using OpenAI APIs — enabling users to assess patent viability from uploaded documents and structured data in **AWS Redshift**, streamlining early-stage IP discovery.
